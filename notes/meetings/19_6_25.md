## Error correcting diffusion
- Start with initial proof attempt, with preallocated state tokens
- Update state with error or result from proof attempt
- Previous proof can then be refined with new context 
- Best candidate approach would be remasking diffusion models
  - Insertion diffusion another option, but not as popular or well studied as masked diffusion
- Need (proof, error, correction) data
  - Can generate some synthetically, not guaranteed the error to correction is useful (e.g. error unrelated to correct proof)
- Advantage over autoregressive:
  - Parallel generation
  - Only needs to edit existing proof
  - Tokens can attend to later parts of the proof 
  - Claims of better diversity across several other diffusion papers vs AR approach
  - Don't need context of previous attempt + new proof, only modification of existing proof
- Potential issues:
  - Lower perplexity often reported vs AR
  - Lack of pre-trained models
  - Insufficient (proof, error, correction) data
  - Diffusion schedule, hyperparams, and how this interacts with context data
