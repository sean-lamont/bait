## LLM agent + RL
- Idea: Use LLM agent, similar to COPRA, but improved with RL following strategy from DeepSeek R1
 
- Contributions:
  - Beyond COPRA, also allow the agent a BACKTRACK action, rather than backtracking on heuristics 
  - Allows for much quicker proofs, as only one tactic executed at a time
  - Allows error correction 
  - Can improve based on previous proofs and failures
  - No separate search algorithm, agent decides on progress and when to backtrack 

- Pipeline:
  - Using previous proofs, generate SFT data for correct tactics, backtracking and errors
    - Backtrack data from open paths at same depth as correct proof
    - Error data from error siblings to a proof
  - Annotate this with reasoning using general purpose QA model (Gemini2.5 Flash)
  - Train LLM (InternLM to start) on this data
    - Since we only consider proofs from original LLM, no contamination from reasoning
  - Run RL loop 
    - Run SFT agent over environment, collect traces
    - Generate GRPO examples 
      - Can group paths with order errors < success < proof 
    - Can allow for more paths for failed attempts (e.g. 1 branch for 1st attempt, 2 for second etc.)

- Progress
  - SFT data gen + rationale tested with Gemini / InternLM (over miniF2F)
  - Tested basic fine-tuning, runs but only with LoRA 

- Other idea:
  - How can we learn from failed proof attempts? 
  - Could possibly have a model that takes a failed attempt, and summarises 'lessons' to train on
