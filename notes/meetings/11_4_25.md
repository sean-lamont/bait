## LLM agent + RL
Train LLM agent (e.g. COPRA) based on previous attempts with RL. 

Why agent? Can consider error messages, previous tactics, etc., as well as common-sense judgements in search,
e.g. if state is clearly false, backtrack. Reasoning models in particular could be useful here.

Why RL? Can improve over multiple attempts.

- COPRA state has current goal, possible lemmas, previous failed tactics + errors
  - Don't need whole attempt history, keeps context smaller 

- Which model to use for training?
  - DeepSeek R1 (general reasoning model) vs Proving model (deepseek/internlm) 

- Use e.g. GPT traces to initialise + distill 
    - Could add additional traces with retrospective rationales, given successful proofs only?

   
## RL setup
- RL using e.g. GRPO, based on proof traces
- What is the state?
  - COPRA state vs whole history
  - Whole history 
    - Very large context
    - GRPO would then be based on multiple attempts per proof
  - Only COPRA state
    - Multiple branches per state to generate good reward data
      - Could start with 1 branch, then if failed, add more
      - Each branch adds previous branches as failed, so they aren't repeated
    - Intermediate rewards or only success/fail
      - E.g. Relative reward for no error vs error
      - Scaled by length / number of LLM queries?
    - PPO vs GRPO
      - GRPO needs multiple examples, but could be more stable
