## Update
### DPP
- Reading
- Can be used to filter out a diverse subset from a given ground set
- For us, it would make sense to use them to filter out a small set from a small ReProver LLM's tactics
  - Why? Small ReProver is very quick at generating a large set of tactics
  - Bottleneck is in effective search and environment run time
  - Filtering a large set of candidates effectively could prune the search tree while ideally keeping 
  the same/simliar semantic proof strategies in search (while removing redundant paths such as e.g. variable renaming)
  - Contrasts with other approach of generating diverse candidates through e.g. VAE
- Idea:
  - Generate K samples from fast LLM
  - Filter to k' < K using DPP.
    - DPP applied using tactic embeddings as feature vectors, where the embeddings are generated to capture
    the semantics of the tactic in the environment transition
    - The magnitude of the vectors are typically normalised, then scaled by a 'quality' score. For our case,
    this naturally is the logprob from the LLM. In this way, a tradeoff between quality and diverse tactics are chosen

### Experiments: Tactic embeddings for environment transitions
- Algo 1: Embed tactic with tac_embedding model and then concatenate with goal embedding, feeding this to decoder to
predict the environment outcome
  - Compared prediction with and without a tactic embedd
  - Shows a clear improvement over no tactic, suggesting some useful transition dynamics are encoded
  - Heatmap shows some good similarity scores, however hard to distinguish from what an e.g. autoencoder might output
    - Some cases where 'opposite' lemmas are scored similar, since they are syntactically similar
    - Not surprising, given the tactic encoder has no access to the lemmas definitions or even the goal

-  Motivated by these opposite similarities, I tried another architecture: Run the goal + tactic through the encoder,
then pool the associated word embeddings for the tactic to create a single tactic embedding vector. 
  - Shows an improvement over the single tactic embedding case from metrics so far
